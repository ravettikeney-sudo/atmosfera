Как установить на Android

Нажмите «Скачать для Android» и откройте скачанный файл atmosfera.apk.

Телефон спросит, можно ли устанавливать приложения из браузера. Нажмите «Настройки» → «Разрешить» и вернитесь назад.

Нажмите «Установить». Иконка «Атмосфера» появится среди приложений. Дальше обновления приходят сами.

Предупреждение «файл может быть опасен» Android показывает для любого приложения не из Google Play. «Атмосфера» не просит доступа к контактам, фото и сообщениям: только к местоположению, чтобы показать погоду там, где вы находитесь.

На iPhone: откройте сайт приложения в Safari, нажмите «Поделиться» → «На экран „Домой“». Иконка появится как у обычного приложения.
