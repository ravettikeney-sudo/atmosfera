# Атмосфера

Погода в любой точке планеты на интерактивном 3D-глобусе: текущие условия, короткий прогноз осадков, прогноз на 48 часов и 16 дней, ветер, давление, качество воздуха. Режим «Погода на карте» с анимацией облаков, дождя и снега на 12 часов, радар, живые спутниковые снимки облаков и звуки погоды.

Открыть: https://ravettikeney-sudo.github.io/atmosfera/

Данные: Open-Meteo, RainViewer, NASA GIBS (GOES, Himawari, VIIRS), Esri World Imagery, BigDataCloud.
