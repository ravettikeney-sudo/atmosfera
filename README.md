# Атмосфера

Погода в любой точке планеты на интерактивном 3D-глобусе: текущие условия, прогноз на 48 часов и 16 дней, осадки, ветер, давление, качество воздуха, радар осадков и живые спутниковые снимки облаков.

Открыть: https://ravettikeney-sudo.github.io/atmosfera/

Данные: Open-Meteo, RainViewer, NASA GIBS (GOES, Himawari, VIIRS), Esri World Imagery, BigDataCloud.
